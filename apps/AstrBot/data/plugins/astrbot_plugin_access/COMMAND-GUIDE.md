# 新插件指令管理指南

> 权限闸门插件（astrbot_plugin_access）配套文档。
> 新插件要接入统一权限管理，照本文做即可；部署步骤见同目录 `DEPLOY-GUIDE.md`。
> 本插件指令总表见仓库 `docs/PLUGIN-COMMANDS.md`。

## 1. 权限模型（三级，全插件统一判定）

| 级别 | 数值 | 谁算 |
|---|---|---|
| 公开 | 0 | 其他人 |
| 管理 | 1 | AstrBot `admins_id` ∪ 兽聚 `FURCON_ADMINS` 环境变量 ∪ 群管理员 |
| 超管 | 2 | access 插件配置 `super_admins` |

判定统一在 `unified_perm.py` / access 的 `_level()`，各插件**不要再自己维护权限名单**。单拎兼容：各插件判断权限时优先 import 本插件的 `unified_perm`，导入失败时 fallback 到 AstrBot 原生 `admins_id`（参考 apimode / furcon 的写法）。

## 2. 闸门如何拦指令

- access 的 gate 以 `GATE_PRIORITY`（最高优先级）最先运行，识别出指令后查权限表，级别不够直接回一句拒绝并 `stop_event()`；够了则放行给各插件自己的 handler。
- 匹配顺序：`prefix`（带参数指令，长键优先）→ `exact`（全等）→ 未知斜线 `__unknown__` → 唤醒后的 `contains` 包含词。
- 权限表实际值落盘在 `cmd_perm.json`，可用 `/权限 设置 <指令> <公开|管理|超管>` 在线改；声明级别只是展示口径，**真正拦截以权限表为准，两者不要矛盾**。

## 3. 指令自声明（必备，2026-11-20 起强制）

每个插件必须在 `main.py` 顶层声明指令清单。access 启动时用 `ast.literal_eval` 安全扫描全部插件目录（只取字面量、不执行插件代码），`/权限 列表` 的按插件分组图卡和 `/指令` 公开卡都从这里读取。**没有声明的插件会在权限表卡片的「⚠ 未声明指令」节被点名，且纯被动插件不会出现在公开卡里。**

### 有斜线指令的插件

```python
# 指令自声明：/权限 列表 与 /指令 公开卡按插件分组展示用（插件开发规范要求）
DECLARED_COMMANDS: dict[str, tuple[str, str]] = {
    "/指令 <参数>": ("一句话说明", "公开"),   # 级别：公开 / 管理 / 超管
    "/指令 子命令": ("一句话说明", "管理"),
}
```

规则：

1. 键写**用户实际输入的完整形式**（带 `/`，带子命令和参数占位）。
2. 值是 `(说明, 级别)` 二元组。
3. 同义别名写进说明里（如 dice：`"掷骰（同义别名：roll/dice/骰）"`），不用每个别名一条。
4. 改了指令（增删改子命令）要同步改声明。

### 纯被动插件（无斜线指令）

```python
DECLARED_COMMANDS: dict[str, tuple[str, str]] = {}
DECLARED_BEHAVIOR = "无斜线指令：一句话说清被动行为（注入防护/复读/缓存等）"
```

纯被动插件（commands 和 behavior 都空）只出现在 `/权限 列表`，不会出现在公开的 `/指令` 卡里。

### 公开卡判定（双重从严）

`/指令` 公开卡只收录**声明级别为公开、且权限表实际级别也为公开**的指令——只看声明会漏掉 handler 内部再拦的，只看闸门会漏掉内部细粒度动作，取两者更严的一档。想让某个指令出现在公开卡，声明和权限表都得是公开。

## 4. 把指令加进默认权限表（可选）

新插件若有需要预设级别的指令，往 `main.py` 的 `DEFAULT_PERM` 里加，选对区块：

- `prefix`：带参数或子命令的指令（如 `切换`、`表情管理`）。
- `exact`：全等匹配的短词（如 `启用`、`用量`——泛用词必须 exact，防止 prefix 误伤）。
- `contains`：仅唤醒后包含匹配的查询词（如 `运势`），**必须全部是公开级**，误命中无害。

不带 `@filter.command` 装饰器、自己手写匹配的指令插件（如兽聚/骰子），还需把模块名加进 `_CMD_LISTENER_MODS`，保证排在主动回复之前；用 CommandFilter 的指令会被 `_autodiscover()` 自动补进表（默认公开，带 ADMIN 过滤器则默认管理），不用手加。

## 5. 上线前检查清单

- [ ] `main.py` 顶层有 `DECLARED_COMMANDS`（Assign 或带类型注解的 AnnAssign 都行，但值必须是字面量）
- [ ] 声明级别与权限表实际级别一致
- [ ] 想公开的指令，确认能出现在 `/指令` 卡上（发一条 `/指令` 看图卡）
- [ ] `/权限 列表` 卡片里你的插件分组显示正常、没有被点名「未声明」
- [ ] 用一个普通用户（非管理员）实测被拦的指令真的被拦
- [ ] 插件单拎出来（删掉 access）还能跑（unified_perm 导入失败走 fallback）
