# 全部指令总表

> 这份文档覆盖**所有**能触发的指令：AstrBot 框架自带 + 本项目装的插件。
> 兽聚类指令的模糊匹配词表另见 [COMMANDS.md](COMMANDS.md)。
> 最后更新：2026-11-20（权限组归并到 astrbot_plugin_access）

---

## 0. 前缀与权限

- 所有指令都走 AstrBot 的唤醒前缀 `/`（`wake_prefix = ["/"]`）
- **权限等级由 astrbot_plugin_access 统一判定，全插件共用**（2026-11-20 起取消各插件独立权限组）：
  - `公开` = 谁都能用
  - `管理` = `admins_id` 管理员名单 ∪ `FURCON_ADMINS`（兼容旧名单）∪ 群管理员角色
  - `超管` = 插件配置 `super_admins`（默认 1154487120，WebUI 可改）
- **每个指令属于哪一级可在聊天里在线改**：`/权限 列表 / 设置 / 检查 / 重置`（见 §1）
- 不在白名单的群/私聊不会响应（`platform_settings.id_whitelist`，`/私聊` 可在线改）

### ⚠ 两套开关必须分清作用域

| 开关 | 作用域 | 存储 | 指令 |
|---|---|---|---|
| **兽聚功能开关** | **对群**（按 group_id） | `data\furcon_enabled.json` | `/启用` `/关闭` 等（见 §3.3） |
| **聊天功能开关** | **对个人**（按 QQ 号） | `platform_settings.id_whitelist` | `/私聊 允许/拒绝`（见 §1.2） |

两者状态独立、互不影响。关了某群的兽聚功能，不影响该群成员被私聊授权；
收回某人的私聊权限，不影响他所在群的兽聚功能。

## 1. 权限闸门（astrbot_plugin_access）

斜线指令最先过闸门鉴权，通过才放行给各插件；级别不够直接拦。同时统一仲裁
handler 优先级（闸门 > 指令 > 纯监听），替代各插件的 maxsize 力大砖飞，
指令抢在主动回复/复读之前跑完。

### 1.1 指令权限表（仅超管）

| 指令 | 说明 | 权限 |
|---|---|---|
| `/权限` `/权限 帮助` | 用法 | 公开 |
| `/权限 列表` | 按插件分组看全部指令（一图流） | 公开 |
| `/权限 列表 <插件名>` | 只看某个插件的指令（如 `/权限 列表 furcon`） | 公开 |
| `/权限 检查 <指令>` | 看某指令当前级别 | 超管 |
| `/权限 设置 <指令> <公开\|管理\|超管>` | 改级别（不在表里的指令会自动入表） | 超管 |
| `/权限 重置 <指令>` | 恢复默认 | 超管 |

级别词兼容：`公开/user/普通`、`管理/admin/管理员`、`超管/super/最高`。
表落盘 `apps\AstrBot\data\plugins\astrbot_plugin_access\cmd_perm.json`，
改完即时生效不用重启。

**插件指令自声明**：权限表按插件分组的展示数据来自各插件 `main.py` 顶层的
`DECLARED_COMMANDS`（ast 安全扫描，不执行插件代码）。全部 11 个插件均已声明；
无斜线指令的插件（peer/repeat/websearch/vision_context）用 `DECLARED_BEHAVIOR`
说明被动行为。新增插件必须带声明（规范见 `docs/MODULE-GUIDE.md` §2.5），
否则会在 `/权限 列表` 的「⚠ 未声明指令」节被点名。

### 1.2 聊天功能开关 · 私聊白名单（对个人）

> **作用域：对个人**（按 QQ 号）。与兽聚功能开关（对群）分开管理。

| 指令 | 说明 | 权限 |
|---|---|---|
| `/私聊 列表` | 看白名单 | 公开 |
| `/私聊 允许 <QQ号>` | 允许对方私聊（对个人生效） | 管理 |
| `/私聊 拒绝 <QQ号>` | 收回私聊权限（对个人生效） | 管理 |
| `/私聊 检查开` / `/私聊 检查关` | 白名单检查总闸 | 管理 |

存储：`platform_settings.id_whitelist`（条目格式 `qq:FriendMessage:<QQ>`）。
管理员本人本来就能私聊，不在白名单也行。

### 1.3 管理员名单（仅超管）

| 指令 | 说明 | 权限 |
|---|---|---|
| `/管理员 列表` | 看管理员名单 | 超管 |
| `/管理员 添加 <QQ号>` | 提升为管理员（裸 QQ 号等价于添加） | 超管 |
| `/管理员 移除 <QQ号>` | 撤掉管理员（超管本人不可移除） | 超管 |

最高管理员名单在 WebUI 插件配置里改（`super_admins`）。

## 8. 联网搜索插件（astrbot_plugin_websearch）

**没有用户指令**，两种触发方式：

1. **自动**：消息像问句（含"什么/怎么/多少钱/最新…"）时，框架自动查 SearXNG（`127.0.0.1:9000`）并塞进提示词
2. **工具**：模型可主动调用 `web_search` 工具（小模型很少自己调）

想在群里临时关掉自动搜索，需要改插件源码里的 `QUESTION_HINTS`，或用 `/set` 关会话级开关（如果框架版本支持）。

## 9. 骰娘插件（astrbot_plugin_dice）

零配置桌游骰子：**只按骰式输出一行随机数**，不调模型、不抢别的指令。源码与说明在
`D:\QQNTBOT-repos\astrbot-plugin-dice`（本地插件目录是
`apps\AstrBot\data\plugins\astrbot_plugin_dice`）。

### 所有人

| 触发 | 输出 | 权限 |
|---|---|---|
| `/r <骰式>` | 一行结果，如 `🎲 2d6+3 = 4+5+3 = 12` | 公开 |
| `/roll`、`/dice`、`/骰`、`/掷骰`、`/投骰` | 同上，别名 | 公开 |
| `/r` | 用法提示 | 公开 |

骰式：`NdM`、`dM`、`d%`（百分骰）、`khN`（取最高 N 颗）、`klN`（取最低 N 颗）、
`!`（爆骰重掷）、`+/-常数`。例：`/r 1d20`、`/r 4d6kh3`、`/r 2d20kl1`、
`/r 1d6!`、`/r 2d6+3`。
上限：100 颗 / 1000 面 / 修正 1000000 / 总掷骰 200 次 / 表达式 64 字符。

> 防抢指令：只注册精确 `command` 过滤器，**没有** `event_message_type(ALL)`、
> 没有正则兜底；只有 `/r ` 等完整命中才接管并 `stop_event()`。优先级归 access 分档
> 统一仲裁（2026-11-20 起），命中后复读机、判官、大模型都不会再补一句。

## 11. 冲突与注意事项

- **指令 vs 主动回复的冲突由权限闸门统一仲裁**：加载时把 handler 分档
  （闸门 > 指令 > 纯监听），指令永远抢在主动回复/复读机之前跑完。
  兽聚插件不再自报 `priority=maxsize`（2026-11-20 起），冲突仲裁权归 astrbot_plugin_access
- **权限组已归并**（2026-11-20 起）：apimode / furcon / visionmode 不再各自维护
  ADMINS 名单，统一由 astrbot_plugin_access 的 `super_admins` + `admins_id` 判定。
  独立插件仓里的旧版（`D:\QQNTBOT-repos\`）仍保留各自名单，以本地热备份为准
- `/help` 是框架的，兽聚帮助用 `/兽聚help`（早期版本曾抢占过 `/help`，已修）
- 骰娘只用 `/r` `/roll` `/dice` `/骰` `/掷骰` `/投骰` 这 6 个精确指令，与其他插件无重叠；
  它不会去猜"像掷骰"的消息，也不会把 `/判官`、`/下次展` 等吞掉
- 所有插件指令都必须带 `/`；不带斜杠只有当消息里出现"阿灰/小灰"才可能被兽聚插件接住
- 带斜杠但没命中任何指令时，消息会被丢弃，**不会进大模型**
- `/reset`、`/new` 需要群管理员及以上；普通群友发了会被拒
- 指令权限表可以在线调任意指令的级别（`/权限 设置`），调整后立刻生效
- **两套开关别混**：兽聚功能开关按群（`/启用` `/关闭`），聊天功能开关按人（`/私聊`），
  状态互相独立

## 12. 怎么核对这份表

指令是代码里注册的，表可能滞后。核对脚本：

```powershell
# 框架自带
Select-String -Path 'D:\QQNTBOT\apps\AstrBot\astrbot\builtin_stars\builtin_commands\main.py' -Pattern '@filter.command'

# 各插件
Get-ChildItem 'D:\QQNTBOT\apps\AstrBot\data\plugins' -Recurse -File -Filter *.py |
  Select-String -Pattern '@filter\.command\(|\.command\("'
```

发现表里没有的，补进对应章节即可。
